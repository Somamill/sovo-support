# App Review setup

sovo. 1.0.2 (18) — iPhone, iPad and Mac Catalyst

Purpose/audience: A personal offline player for listeners with lawful DRM-free audiobook files. Imports, chapters, bookmarks, queues, speed, sleep timers, automatic metadata and optional iCloud keep a private library easy to use. Compatible multi-file imports automatically create chaptered M4B locally; originals are retained. There is no torrent client or commercial audio catalogue.

Access: No sovo. account, registration, payment, subscription or demo credentials are required. Launch → Library → + → Download a file. Paste this small two-minute sample URL and select Download:
https://raw.githubusercontent.com/Somamill/sovo-support/main/samples/alice-preview.m4b
Tap the imported preview: playback starts immediately. Open Chapters (Chapter - 01), change speed, bookmark, set a timer, pause/resume, and inspect Details. Alternatively save the sample to Files and use + → Import audio files. Mac supports Command-O and Command-Shift-O. The optional full classic is about 77 MB and can download slowly; use the small sample for a quick review.

Sample rights/credits:
https://github.com/Somamill/sovo-support/blob/main/samples/AUDIO-CREDITS.md
Lewis Carroll, read by Kara Shallenberg (LibriVox, 2010). Public-domain recording in the USA; regional status may vary. No protected commercial audio is supplied. User imports must be authorized. Audio is not uploaded for metadata matching.

Reading shelves: Settings → Goodreads is optional. Provider sign-in takes place on Goodreads/Amazon in a separate app-owned website session. It is read-only shelf integration, not automatic listening-progress writeback. Provider CAPTCHA/private shelves can limit access. CSV snapshot import needs no login; sample and instructions:
https://github.com/Somamill/sovo-support/blob/main/REVIEW.md
There is no sovo. account creation/deletion, public feed, messaging or user-content hosting. Disconnect removes local provider connection data; external accounts are administered by their providers. No paid features or IAP.

External services: optional Apple iCloud Drive/key-value storage; Apple Books Search and Open Library for bibliographic metadata/covers; Wikipedia/Wikimedia for attributed biographies/portraits; Goodreads/Amazon and provider CAPTCHA resources; optional user-configured Audiobookshelf/Jellyfin/HTTPS servers and trusted-LAN transfer; LibriVox/Internet Archive optional classic and GitHub-hosted review sample. No runtime AI service or advertising SDK. iCloud requires the user's Apple account and enabled Drive; provider cookies stay per device.

Regions: Features are consistent across regions; provider availability, public-domain rights, network access and user-supplied content vary. Twelve UI languages are included with AI-assisted translations; original book metadata retains its language. No regulated service, HealthKit/pulse access or medical sleep detection is offered.
